# 🚀 AI Interview Platform - Demo & Testing Guide

This guide provides the complete flow of pages and steps to thoroughly test all features of the AI Interview Platform with a sample workflow.

## 🔄 Complete Page Flow

The application is structured to guide the user from landing, through authentication, and into various AI-powered tools.

1. **Landing & Authentication (`/`)**
   - **Page**: `Home.jsx`
   - **Action**: User lands on the homepage. They can sign up or log in using Firebase Authentication.
   - **Flow**: Upon successful login, the user is redirected to the Dashboard.

2. **User Hub (`/dashboard`)**
   - **Page**: `Dashboard.jsx`
   - **Action**: The central hub. Displays user stats, remaining credits, and entry points to all 4 main features (Interviews, Resume Scorer, Resume Builder, Roadmap) and Billing.

3. **Feature 1: AI Mock Interview**
   - **Step A: Setup (`/interview`)** - `InterviewStart.jsx`: User configures the interview (job role, tech stack, experience level).
   - **Step B: Active Interview (`/interview/:id`)** - `InterviewPage.jsx`: The actual interactive AI interview session.
   - **Step C: Results (`/interview/:id/report`)** - `InterviewReport.jsx`: Comprehensive feedback, score, and transcript analysis post-interview.

4. **Feature 2: AI Resume Scorer (`/scorer`)**
   - **Page**: `Scorer.jsx`
   - **Action**: User uploads their existing resume and pastes a target job description. The AI analyzes the match, provides an ATS score, and suggests improvements.

5. **Feature 3: Resume Builder (`/resume`)**
   - **Page**: `ResumeBuilder.jsx`
   - **Action**: An interactive editor where the user can build a professional, ATS-friendly resume from scratch or update an existing one saved in the database.

6. **Feature 4: Career Roadmap (`/roadmap`)**
   - **Page**: `Roadmap.jsx`
   - **Action**: User inputs their current role, target role, and timeline. The AI generates a step-by-step visual learning path and career progression roadmap.

7. **Billing & Credits (`/billing`)**
   - **Page**: `Billing.jsx`
   - **Action**: User can view their credit usage, upgrade their plan, and manage subscriptions via Stripe (or integrated payment gateway).

## 🧪 How to Test with a Sample Flow (Demo Script)

To fully test the project, follow this sample end-to-end workflow:

### Step 1: Initial Setup & Login
1. Ensure your backend infrastructure is running (`docker-compose up -d` in the backend folder).
2. Start all microservices and the gateway (`backend/gateway`, `backend/services/*`).
3. Start the Vite frontend (`npm run dev` in the frontend folder).
4. Navigate to `http://localhost:5173`.
5. **Test**: Sign up or log in with a test account (e.g., Google Auth). Ensure it redirects to `/dashboard`.

### Step 2: Build a Base Resume
1. From the dashboard, click **"Resume Builder"**.
2. **Test**: Fill in dummy data for Personal Info, Education (e.g., B.Tech in CS), and Experience (e.g., Software Engineer Intern). 
3. **Save**: Ensure the data saves correctly and reflects on the page.

### Step 3: Score the Resume
1. Go back to the Dashboard and click **"Resume Scorer"**.
2. **Test**: Paste a sample Job Description for a "Frontend React Developer". 
3. **Action**: Click 'Score'. Verify that the AI provides an ATS score and actionable feedback based on the resume data.

### Step 4: Conduct a Mock Interview
1. From the dashboard, navigate to the Interview section.
2. **Test**: Enter "React Developer" as the role and "1-2 years" experience.
3. **Action**: Start the interview. Answer 2-3 questions generated by the AI.
4. **Finish**: End the interview and verify the app redirects to the **Interview Report** page. Check if the AI generated accurate feedback for your answers.

### Step 5: Generate a Career Roadmap
1. From the dashboard, click on **"Career Roadmap"**.
2. **Test**: Enter current role: "Junior React Developer", Target Role: "Full Stack MERN Developer", Timeline: "6 Months".
3. **Action**: Click generate. Verify the UI renders a timeline or step-by-step learning path successfully.

### Step 6: Test Billing & Limits
1. Navigate to **"Billing"**.
2. **Test**: Check if the credits decremented after using the AI features (Scorer, Interview, Roadmap).
3. (Optional) Test the upgrade/subscription flow if a mock payment gateway is configured.

---
*By following this script, you will hit every major microservice (Auth, Resume, Interview, Roadmap, Billing) and validate the complete frontend routing.*
